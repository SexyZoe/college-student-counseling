# 假期学生离校统计

进入“假期学生离校统计”。左侧为月历，右侧为当前辅导员负责的学生档案。可先勾选学生再切换日期，逐人填写离校、去向、家长报备、心理状态和返校情况，或对所选学生批量登记同一天的心理状态。管理员可查看全部学生并按辅导员筛选。

## 假期和逐日记录

辅导员可建立和维护本人假期；管理员只读查看、按日期导出，无新建、编辑、上传及批量登记权限。日期范围最长 92 天，允许跨月和跨年；等级参考月份单独指定，不推断学生等级。已有记录后不能缩短范围以排除已填日期，也不能改写等级参考月份。可以扩大范围。

心理状态逐日单独保存，未填日期留空，不会自动视为稳定。新一天可以带入此前最近记录中的离校、去向、报备、截图及返校信息，界面显示来源日期供填写人核对。当天备注单独填写。每次保存保留时间、操作人和加密历史版本，旧版本并发提交会被拒绝；批量登记中任何一名学生无权限或发生版本冲突，整批回滚。

名单及日历查询均限于有权访问的学生。学生档案交接后访问权限跟随当前负责辅导员，历史内容和原填写时间仍保留。私人假期仅创建人及管理员可见，既有共用假期保留为只读日期范围，管理员也不能修改。

## 确认截图

支持单张 PNG/JPG 截图，最大 2MB，边长不超过 4096 像素且总像素不超过 1200 万。服务端检查图片内容，截图按现有数据保护配置加密保存，仅上传者、有权访问相关记录的辅导员及管理员可读取。移除当前截图不会抹去历史版本中的截图。

导出时可以选择是否嵌入图片。截图以原比例放入“与父母报备情况”栏，报备文字保留在同一栏的上方；可在 Excel 中放大查看图片。

## 按日期导出

支持单日、自选区间和整个假期，学生范围可选择当前筛选的全部学生、仅勾选学生，或所选日期有保存记录的学生。姓名、学院、辅导员和等级筛选继续适用；单日心理状态筛选不限制区间导出。每次最多 500 名学生。

使用用户提供的《信息与人工智能学院心理库学生离校统计表9.30.xlsx》作为模板，保留 22 列字段及顺序、原边框和内容含义。导出默认使用“清晰排版”：统一 11 磅字体，表头完整换行，加宽报备截图、备注、年级专业等栏位，隐藏未选日期的空白列；无图学生行按实际内容收紧，有图的行单独预留文字与截图空间。截图保持比例并锚定在报备单元格内部，不覆盖文字或相邻列。超过 Excel 单行高度容量时明确提示，不截断保存内容。

也可选择“学校原版列宽”，沿用学校原列宽与表头字体；表头高度仍按内容适配，截图仍修正边界。原始模板文件保持不变。

打印纸张可选 A3 横向或 A4 横向，宽表默认推荐 A3。表格按一页宽度缩放，纵向自然分页，每页重复完整表头，页边距适当收紧。可在 Excel 中继续调整打印设置。

G 栏显示所设参考月份的等级；M—T 保留 8 个每日状态栏，按导出日期更新表头，不足 8 天的多余栏留空并在清晰排版中隐藏。超过 8 天时每 8 天生成一个工作表，保留原表的 22 列结构；U 栏显示该工作表最后一个选定日期的返校情况。日期表头包含年份，跨年时不会混淆。I 栏使用真正的 Excel 日期值，显示为原表的月.日形式。

每张工作表的离校、报备、截图及返校信息使用截至该表最后一天的最近记录；不会将之后的记录回填。当天心理状态来自对应日期记录。L 栏汇总该工作表选定日期内的备注，区间导出时标明备注日期。没有记录时使用当前档案的基本信息，假期状态保持空白。

原文件中的样本学生、联系方式、报备截图、公式和 WPS 隐藏图片目录不会导入或复制到模板。模板只保存表格版式，导出只填入当前用户有权访问的系统数据。

## 本地预览与验证

`npm run preview:holidays` 启动 `http://127.0.0.1:8790/web/#holidays`，只监听本机地址。演示使用虚构记录和确认截图，内存数据在重启后重置；正式应用仍使用已配置的 SQLite/MySQL 持久化数据库。管理员 `admin`、辅导员 `T001` 和 `T002` 的本地演示密码均为 `123456`。

新增 SQLite/MySQL 迁移 013。后端测试覆盖权限、日期范围、跨年、图片验证和加密、按日版本、批量事务、原表格式、图片实际嵌入、8 天分页、历史截止日期及重启持久化。`npm run test:holidays:web` 覆盖真实页面的选人、日历切换、填写、图片上传、导出、历史查看、跨年和手机宽度。SQLite 本机已运行验证，MySQL 需在目标实例执行迁移验收。本次没有同步 GitHub 或学校服务器。

`node scripts/holiday-layout-check.js` 使用虚构记录生成单日、8 日、无截图、原版和多页导出，转换为实际 PDF 和 PNG。检查表头是否完整且每页重复、截图是否留在报备列及对应学生行内、截图比例及文字遮挡，并保留渲染图供查看。布局检查依赖本机文档转换器、Poppler 和 Python pdfplumber。
