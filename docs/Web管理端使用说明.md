# Web 管理端使用说明

## 入口和角色

校园网内访问 `http://172.18.132.12/web/` 即可打开管理端。Web 端与微信小程序共用 Node.js API、MySQL 数据库和同一套角色权限。

- 管理员：总览、学生名单导入、账号重置、内容审核、测评任务和审计日志。
- 辅导员：授权班级、学生摘要、风险跟进和图文/视频投稿。
- 学生：不登录 Web 管理端，继续使用微信小程序。

页面使用响应式布局，辅导员可以在电脑或手机浏览器操作。

## 学生名单导入

管理员进入“学生与名单”，选择 `.xlsx`、`.txt` 或 `.csv` 文件。表头和顺序必须为：

```text
班级,学号
软件工程1班,20260001
```

Excel 需使用 `.xlsx` 格式；TXT 可使用逗号或 Tab 分隔。浏览器先将文件解析为标准两列名单，服务器再执行班级、学号、重复行和数据冲突检查。只有点击“确认导入”才会写入数据库。新账号初始密码为学号后4位，首次登录必须修改。

## 图片和视频内容

辅导员进入“文章发布”，填写标题、分类、摘要和正文，可从本地选择最多 9 个文件。

- 图片：JPG、PNG、GIF、WebP。
- 视频：MP4、WebM、MOV；推荐 MP4 以获得更好的手机兼容性。
- 单个文件最大 100MB。

服务器同时检查 MIME 类型和文件头签名，不只信任文件后缀。文章默认为“待审核”，管理员通过后，微信小程序的心理科普/成长与价值页面会读取同一文章和媒体。

## 数据与部署

媒体元数据保存在 MySQL，文件保存在 Docker 命名卷 `media-uploads`。应用容器重建不会删除该卷。发布前需确认 Nginx 的请求体上限和 `MAX_MEDIA_BYTES` 一致。

当前校园内网使用 HTTP。微信正式版和校外访问仍需 HTTPS 域名、证书和微信合法域名配置。
