# 人员数据导入与回滚说明

> 学生名单入口现已改为固定两列「班级、学号」，请使用[学生名单与账号管理](学生名单与账号管理.md)。以下八列格式仅记录已有组织管理兼容接口，不再是小程序学生入口模板。

## 1. 功能范围

本功能用于学校数据 API 尚未接通时，由管理员通过 CSV 批量维护班级、学生、辅导员和“辅导员—班级—学期”分配关系。导入采用“预检—确认—回滚”三阶段，预检不会修改正式数据。

当前稳定格式为 CSV，单批最多 500 行、512KB。XLSX 直接解析暂未开放，Excel 文件可先另存为 UTF-8 CSV。

## 2. CSV 模板

```csv
类型,账号,姓名,班级编号,班级名称,专业,学期编号,初始密码
班级,,,CS2501,计科2501,计算机科学与技术,,
学生,2025001,示例学生,CS2501,,,,ChangeMe123
辅导员,t002,示例辅导员,,,,,
分配,t002,,CS2501,,,2026-1,
```

支持四类记录：

- `班级`：必须填写班级编号和班级名称。
- `学生`：必须填写账号、姓名和班级编号；新增账号必须提供 8–64 位初始密码。
- `辅导员`：必须填写账号和姓名；账号由管理员创建，系统统一设置临时密码 `123456`，首次登录强制修改。
- `分配`：必须填写辅导员账号、班级编号和已存在的学期编号。同一学期同一班级只允许一名当前负责人，更换请在 Web 管理端操作。

初始密码只在内存中转换为 PBKDF2 摘要，批次预览和数据库计划中均不保存明文。建议首次登录后通过正式身份系统强制改密。

## 3. 预检规则

- 校验文件表头、行数、字段长度和标识符格式。
- 检查同一文件中的重复账号、班级或分配关系。
- 检查账号是否被其他角色占用。
- 检查学生班级、辅导员、班级和学期引用是否存在，允许同一文件先创建后引用。
- 区分新增、更新和无变化记录，并展示差异数量。
- 同一 `clientBatchId` 和同一文件可幂等重试；批次编号对应不同文件时拒绝覆盖。

## 4. 确认和回滚

管理员确认后，班级、账号和分配关系在一个数据库事务中写入；任意一步失败都会整体撤销。每项新增或更新都会保存导入前后快照，并记录审计日志。

整批回滚时：

- 本批新建的账号、班级和分配关系会被停用，不物理删除，从而保留可能已经产生的历史关联。
- 本批更新的数据会恢复为导入前快照。
- 如果确认后相关数据又被其他操作修改，系统拒绝自动覆盖并返回 `IMPORT_ROLLBACK_STALE`，需要管理员人工处理。
- 重复确认和重复回滚均为幂等操作。

## 5. 权限和限制

- 所有导入、确认、查询和回滚接口仅允许管理员角色访问。
- 小程序必须启用后端同步并重新登录管理员账号后才能导入。
- 当前 SQLite 实现适合本地原型和接口联调；生产环境仍需数据库迁移、备份、审批和操作告警。
- CSV 中包含初始密码时应通过安全渠道传递，并在导入后立即删除源文件。
