# 数智心港湾本地容器压力测试报告

> 测试日期：2026-08-14
> 性质：开发机基线测试，不代表生产容量验收。

## 一、测试目的

验证容器在并发请求下的基本稳定性，并发现同步密码计算对Node事件循环的阻塞问题。测试使用Docker Desktop、虚构账号和单个后端实例；初始基线使用SQLite，2026-08-14又使用真实 MySQL 8.4运行模式复测。

## 二、测试结果

| 数据库/场景 | 请求数 | 并发 | 成功率 | 吞吐 | P95 |
|---|---:|---:|---:|---:|---:|
| SQLite `/ready`就绪查询 | 2,000 | 100 | 100% | 约6,507请求/秒 | 约61ms |
| SQLite 登录（优化前） | 200 | 20 | 97% | 约21请求/秒 | 约4,382ms |
| SQLite 登录（异步PBKDF2优化后） | 200 | 20 | 100% | 约117请求/秒 | 约200ms |
| MySQL 8.4 `/ready`就绪查询 | 2,000 | 100 | 100% | 约6,253请求/秒 | 约57ms |
| MySQL 8.4 登录 | 200 | 20 | 100% | 约115请求/秒 | 约194ms |

登录优化没有降低密码强度；密码校验从阻塞事件循环的同步计算改为异步线程池，并保留PBKDF2-SHA256 600,000次迭代。容器默认`UV_THREADPOOL_SIZE=8`。

## 三、复现命令

健康场景：

```bash
BASE_URL=http://127.0.0.1:8787 \
LOAD_PROFILE=health TOTAL_REQUESTS=2000 CONCURRENCY=100 \
node server/scripts/load-test.js
```

登录场景仅可对虚构测试账号运行：

```bash
BASE_URL=http://127.0.0.1:8787 \
LOAD_PROFILE=login TOTAL_REQUESTS=200 CONCURRENCY=20 \
REQUEST_TIMEOUT_MS=10000 MAX_P95_MS=5000 \
node server/scripts/load-test.js
```

脚本输出请求数、吞吐、错误率、状态码及P50/P95/P99，并在超过`MAX_ERROR_RATE`或`MAX_P95_MS`时返回失败状态。

## 四、不能据此得出的结论

本报告不能证明系统已经支持2,000名学生同时登录或交卷，原因包括：

- 开发机性能与学校服务器/华为云规格不同；
- MySQL运行时已完成契约验收，但尚未在学校或华为云目标规格上进行综合压力测试；
- 未包含网关、WAF、HTTPS、学校统一认证、真实网络延迟和消息通知；
- 未模拟2,000个独立账号、阶段暂存、集中交卷、辅导员实时查询和报表并发；
- 单实例测试没有覆盖负载均衡、扩缩容和实例故障。

## 五、正式容量验收标准

学校确定部署方案后，在预发布环境准备至少2,000个虚构账号，按实际峰值模型执行30分钟稳态和5分钟峰值测试。建议验收目标：业务错误率低于0.1%，核心接口P95低于1秒、P99低于2秒，无重复结果、无越权、无数据库连接耗尽，并在单实例故障后继续提供服务。最终阈值由学校信息中心和项目负责人确认。
