# 学生谈话记录功能说明

辅导员在“学生谈话记录”中在线填写学校要求的谈话表。一次谈话对应一条独立记录；学生档案与谈话表关联可选，尚未建立学生档案时也可以手动填写。

## 填写和保存

辅导员点击“新建谈话记录”，可选择本人负责的学生档案带入姓名、性别、学院、年级专业及学号。班级需要补充到“年级专业班级”栏。按实际谈话选择近期心理困扰，填写具体谈话内容和谈话日期。

姓名用于识别记录，保存时必填。其他尚未完成的项目可以先留空保存，之后继续编辑。谈话日期默认中国时区的今天，允许改成实际日期。系统分别显示首次保存和最后修改时间，修改不会改变首次保存时间。同一学生的多次谈话分别建档。

网络失败时填写内容留在当前对话框内，重试保存不会重复创建同一记录。关闭未保存的填写窗口或离开页面会提示。系统不把谈话内容写入浏览器本地存储；关闭页面前应点击“保存记录”。旧版本覆盖会被拒绝，需要重新打开记录。

## 角色与查看范围

辅导员只读写本人创建的谈话记录，不允许伪造其他辅导员的归属或关联其他辅导员的学生。管理员能按辅导员、学生和谈话日期查询全部记录，打开查看或导出原表，不能修改或代写辅导员记录。停用辅导员账号会撤销会话，已有记录保留供管理员查看。

列表只包含身份摘要、日期、保存时间、修改时间和完整性提示，不返回谈话正文。正文保存在独立的 `talk_records` 表，沿用现有生产加密密钥。审计只写入记录ID、版本、格式等操作元数据，不写谈话正文。

## 学校原表与导出打印

模板取自用户提供的《辅导员心理谈话表 (1).doc》。原件完整保存在 `server/templates/talk-form/original.doc`，其SHA-256记录在同目录清单中。派生DOCX保留原件排版；仅修正文件格式转换造成的表格宽度、首列边线舍入差异及过时文档元数据标题，校验依据仍是原始DOC渲染结果。

固定保留：一页A4纵向；标题、字段、心理困扰栏、五行内容区；原表表格尺寸、合并结构、边框、页边距；辅导员与学生签名栏。心理困扰栏只显示勾选的选项及其原编号，多选使用分号分隔；仅在选中“其他”时附上填写的内容，未选项不出现在预览、Word、PDF或打印结果中。日期填写到原“日期”位置，两个签名栏空白供手签。学号、系统时间、记录人和平台按钮不加入导出表。

导出前先保存最新修改。可导出学校使用的旧版 Word `.doc`，或 PDF。API额外支持 `.docx`。打印预览直接展示实际生成的PDF，点击PDF自带打印按钮，或“打开PDF打印”后使用浏览器打印。选择A4、实际大小，避免打印机额外缩放。

保存允许长记录，导出前必须补齐原表资料。原表只有五个正文段落槽位，系统按原字号换行填入；超过容量时提示精简，不截断文字、不缩小字号、不擅自增加页面。姓名、性别、学院的较长内容会在原有单元格内换行：保留原字号，仅在需要换行的填写格内使用12磅行距，让两行完整文字保持在原行高内。短内容仍使用原段落行距。超长的基本信息或其他选项仍可能挤大表格，系统会明确提示具体栏位，已保存内容继续保留。

每次生成都将输出与原始DOC在同一文档转换器和字体环境下比较：一页、页面尺寸及13条表格边线的坐标，容差0.06磅。`.doc` 导出还会再转换成PDF复核。只有校验通过才返回文件。临时生成文件位于仅进程用户可读的目录，完成或失败均清除，不把学生PDF长期缓存。

## 字体与部署条件

原件指定宋体、黑体。Word保留这两个字体定义。本机缺少原字体，PDF预览使用系统兼容的中文宋体/黑体替代字体，界面有明确提示；因此当前不能承诺字形与学校电脑逐像素相同。若学校要求字形完全一致，需合法提供并安装相同版本的宋体、黑体，然后验收、设置 `DOCUMENT_FONTS_EXACT=true` 并重启服务。该配置是部署方的验收声明，不会自动安装或验证字体文件。

Node服务还需要LibreOffice Writer进行文档转换。Codex本地运行时自动使用随运行时提供的转换器；其他环境通过 `DOCUMENT_CONVERTER_PATH` 指定。Docker运行镜像已加入Writer和Noto CJK兼容字体并复制模板，仍需在实际部署环境构建验证。转换器缺失或超时时，界面显示明确错误，档案保存功能仍可使用。

数据库新增SQLite/MySQL `009_talk_records` 迁移；现有用户、学生档案和导入资料不变。SQLite启动时自动迁移；MySQL需按现有部署流程先执行迁移。并发生成在单实例内排队，限制排队数量、单次转换时间和用户请求频率。

## 验证

`npm test` 运行后端权限、加密、时间、独立保存、重试、版本冲突、模板结构、Word/PDF生成和历史功能回归。

`BROWSER_CHANNEL=chrome npm run test:web` 验证原登记功能及谈话记录的在线填写、保存修改、资料带入、未保存提醒、Word下载、真实PDF预览、管理员只读查看、手机布局和退出清理。所有自动测试使用内存数据库和虚构内容，不写入当前预览数据库。

本地验证范围为SQLite、Chrome和本地LibreOffice。MySQL实例、Linux镜像构建及学校原字体环境仍需部署验收。
