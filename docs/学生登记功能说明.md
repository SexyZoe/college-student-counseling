# 学生登记功能说明

第一阶段：辅导员学生档案、Excel 导入导出与打印。

## 账号和负责范围

管理员登录后进入“辅导员账号”，输入登录工号即可开通账号。工号由2至32位字母、数字、下划线或短横线组成。临时密码为 `123456`，辅导员首次登录必须改密。管理员可以启用、停用或重置账号密码；停用会撤销登录会话，保留该辅导员负责的学生档案，管理员仍可查询。

辅导员在“我的资料与账号”中填写姓名、学院与联系方式。新建登记时默认带入学院及辅导员姓名/联系方式；已存在的学生表内联系信息保留录入时的内容，可逐条修改。管理员不代填辅导员个人资料。

辅导员只能访问自己负责的学生；修改请求、导入确认、导出和打印同样由后端校验。管理员可查看全校数据，按负责辅导员筛选，也可指定辅导员新增或导入学生。学生档案与旧学生登录账号分开存储，不会创建学生登录账号。

## 手动登记与等级历史

在“学生登记管理”点击“新增登记”。学院、姓名、年级专业必填，其余按实际情况填写。可选学号用于明确识别，不以姓名作为唯一标识。

表内的“学生帮扶/班级职务/联系方式”及“领导帮扶”保持自由文本区域，便于与原表一致；暂未增加新的帮扶角色或帮扶流程。

等级按 `YYYY-MM` 保存，暂不预设等级枚举。编辑时可切换月份补录；清空某月等级并保存，会删除该月等级记录。其他已填写月份继续保留。多人同时编辑同一档案时，后提交的旧版本会收到冲突提示，需要重新打开档案。

重复学号阻止新增。同学院、同年级专业的同名学生会提示核对；确认为不同学生时，勾选重名确认即可单独建档。重复判断不会向辅导员暴露其他辅导员档案的姓名、内容或归属。

## Excel 导入

建议先下载模板，填好后上传。支持 `.xlsx`，旧 `.xls` 需在 Excel 中另存为 `.xlsx`；暂不支持加密文件、公式单元格或多个登记工作表同时导入。

每次最多5MB、2000条学生记录、100列；允许标题行、换行表头、空白行，以及最多三行组成的表头。必需识别“学院”“姓名”“年级专业”，其他缺少的列按空值处理。

原表的12列按顺序保留，末尾附有可选学号列。`2026年10月等级` 等带年月表头按列名存储，可以同时导入多个月的等级；仅写“等级”的列使用上传时选择的年月。

手机号和学号建议将 Excel 单元格格式设为文本再填写，以保留前导零。若数字在源文件中已经丢失前导零，系统无法还原。

上传后查看完整字段预览、原 Excel 行号、错误原因和同名提示。存在错误行时整个批次不能入库，需要在源文件修正后重新上传；同名提示需要核对确认。系统不会自动覆盖已有档案。

预览15分钟内有效，只有上传该批次的本人能够确认。确认前再次检查重复和辅导员状态；一个批次在事务内整体写入，重复点击确认返回同一结果。预览内容在入库后移除；过期预览在下一次上传时清理。

## 查询、导出与打印

可按关键词、学院、等级年月、等级筛选；管理员还可按辅导员筛选。关键词查询姓名、学号、学院、年级专业、宿舍和联系方式。

未勾选学生时，导出和打印当前查询全部结果；勾选后只操作当前结果中选中的学生。每次改变查询会清除勾选，避免误带入旧选择。

“导出 Excel”使用原表的列顺序，并在最后附加可选学号；等级列使用选定年月。已设置横向纸张、适应一页宽度、重复标题行和换行。Excel 文件仅包含该次选定月份的等级，其他月份继续保存在数据库中。

“打印 / 保存 PDF”打开浏览器打印窗口：A4横向、原表12列、跨页重复表头。可选择打印机，也可选择“另存为 PDF”。浏览器页眉页脚可按需要关闭。特别长的备注建议在打印预览中检查分页。

导出和打印均记录操作人、时间、记录数量与年月；审计不写入学生姓名、联系方式或档案正文。

## 数据兼容与验证范围

新增 SQLite / MySQL `008_student_registry` 迁移：`counselor_profiles`、`registry_students`、`registry_imports`。已有学生账号、测评与其他历史数据不会被删除或自动转成心理关注档案。档案支持沿用现有 `DATA_ENCRYPTION_KEY` 加密。

本地自动验证使用虚构资料及内存 SQLite，覆盖接口权限与浏览器操作。MySQL 需要在部署环境执行迁移并运行数据库验收；本阶段没有连接或修改生产数据库。
