## 功能迁移对照

| 微信功能 | 网页入口 / 处理方式 |
|---|---|
| 首页、我的、登录、账号设置 | 统一网页登录、角色分流、首次资料初始化和改密 |

| 原始答案与结果 | 继续写入原有业务表；不迁移成浏览器本地“正式结果” |

| 雷达图 | 原实现可从单个总分模拟五维数据；正式网页不延续模拟维度，展示真实单量表指数及同量表历史 |

| 人格探索 | 28题、16类型及维度评分；结果仅在当前页面内存中显示，不进入心理风险系统 |
| 求助与隐私 | 学校配置的信息；未收到的学校信息明确显示待确认，不编造联系电话 |
| 辅导员页面 | 班级、学生必要摘要、风险跟进、图文视频投稿 |
| 管理员页面 | 学期、名单导入预检/确认/回滚、辅导员与分班、任务创建/发布/结束、内容审核、审计 |

## 数据兼容与回退

本次迁移没有修改历史迁移文件，也没有删除、重建业务表。新网页与原服务端使用相同账号、学期、任务和结果表；新增同意记录写入既有审计表。数据库加密密钥必须继续使用原值，否则历史加密数据不可读。

源代码备份不等于数据库备份。发布前需要同时备份 MySQL、媒体卷、环境配置，并将密钥单独妥善保存。

推荐发布前保留旧镜像ID、当前提交和数据库/媒体备份。若需服务回退，用旧代码构建或启动记录的旧镜像，不删除数据卷，不执行 `docker compose down -v`。本次无新数据库结构变更，仍应在隔离环境验证旧版本能读取最新业务数据后再切回。
