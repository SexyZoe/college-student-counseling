# 班级心理委员与原表导出

班级心理委员作为班级工作联系人单独管理，与心理关注学生档案分开保存。

## 使用流程与权限

1. 选择已建立的学期，添加班级，填写学院、校区、年级专业班级。
2. 辅导员新建班级自动归属本人，不能替其他辅导员建班或访问他人的名单。管理员仅可查阅与导出，不能新建、编辑、停用或调整班级归属。
3. 在班级下添加多名心理委员，登记姓名、性别、联系方式及可选学号。同一学期、学院、校区下的班级名称不能重复；同班在任委员有重复核对和旧页面修改冲突提示。
4. 换届时将原委员设为“已离任”，保留记录。默认查询和导出在任委员，可改为“已离任”或“全部委员”。停用班级的名单继续保留，可勾选“包含停用班级”查询。
5. “沿用到其他学期”复制班级与当前在任委员，原学期名单不变。此操作仅限班级负责辅导员；目标学期已存在同名班级时提示核对，不覆盖旧名单。

管理员汇总查看全部数据，按学期、学院、校区、辅导员、班级或委员姓名、学号、联系方式筛选。管理员查看委员明细，不代替辅导员编辑个人任职记录；不能维护班级归属或原表表头。

## 学校 Excel 原表

“按学校原表导出 Excel”使用学校提供的《心理危机四级预警网络》工作簿。保留“正面”“反面”两个工作表及原有字体定义、列宽、边框、对齐、页边距、纸张和打印比例。

- 正面保持6列：校区、辅导员、年级专业班级、心理委员、性别、联系方式。按学院分别生成，再按校区、辅导员、班级分组，对相邻的同组记录重新合并单元格。
- 标题填入实际学院。校心理专职教师、学院心理工作负责人及联系方式由辅导员在“原表表头设置”维护，仅用于本人班级；同学院其他辅导员的设置相互独立；空缺时留空，不挪用学校样表中的人员信息。
- 有班级而没有符合条件的在任委员时，默认在任导出保留该班级的空白委员行，提醒补充名单。指定离任名单且没有符合条件记录时不产生无关空行。
- 普通数据保留模板行高；长文字仅增加相应行高，保持原字号与列宽，不截断文字。名单可按原样式续行，后续页重复前4行表头。超过原表表头或单行容量时返回明确错误，保存的数据完整保留。
- 反面保留原表的工作对接栏目、签名区、行高和合并结构。时间、地点和具体记录留空，由实际工作填写。
- 当前范围只有一个学院时下载 `.xlsx`；多个学院时下载 `.zip`，其中每个学院各有一份原表 `.xlsx`，每份仍保留正反两个工作表。
- 联系方式按文本写入，保留前导零。以 `=` 等字符开头的输入作为文本，不作为 Excel 公式执行。导出有审计记录。

模板存于 `server/templates/committee-network/blank.xlsx`，由原件去除样本人员、联系方式、工作记录及隐藏共享字符串后生成，版式样式部件保留。清理脚本为 `scripts/prepare-network-template.js`，清理后模板有 SHA-256 校验。

## 按教师选择表格与预览

点击“按学校原表导出 Excel”先打开选择窗口，不会直接下载。窗口沿用当前学期、学院、校区、教师、班级或姓名关键词及任职状态的查询范围，按教师和学院列出独立文件。

1. 按教师姓名、工号或学院查找。可勾选某位教师的全部当前表格，也可以逐份勾选；默认不勾选任何文件。
2. 点击“预览”，查看实际 Excel 转换的正面名单和反面对接表；可切换表格区域、整页纸张和放大比例。预览不会自动勾选。
3. 点击“单独下载 Excel”下载该份文件；或勾选后点击底部按钮，一份直接下载 Excel，多份仅将所选文件打包为 ZIP。
4. 过滤列表会保留此前勾选的文件，底部持续显示总选择数。“全选当前列表”仅作用于当前可见文件；“清空选择”取消全部选择。

若教师在选择、预览后保存了新内容，服务端会拒绝使用旧列表下载，提示重新载入列表。重新载入后清空选择与预览，需要重新确认。管理员的操作均为只读，预览和导出保留审计，不改变原记录。

单次可选择 1—100 份文件；单个预览最多 30 页，完整 Excel 下载不因预览页数限制而截断。预览转换失败时仍可下载 Excel。预览采用兼容中文字体，原表 Excel 字体定义不变。转换配置复用现有 documentConverterPath / documentRasterizerPath，临时文件生成于独立私有目录，完成后清理。

验证：`node --test server/test/committee-export-choice.test.js`、`npm run test:committee:export:web`。覆盖教师及学院选择、单文件和所选 ZIP、越权隔离、更新保护、实际正反面预览、窄屏和退出清理。
