# 角色权限说明

| 功能 | 辅导员 | 管理员 |
| --- | --- | --- |
| 辅导员账号开通、启停、密码重置 | 无 | 可管理 |
| 姓名、学院、联系方式 | 维护本人资料 | 无权修改辅导员资料 |
| 学期、当前学期与校历 | 查看 | 管理；已有周记录时保留历史约束 |
| 学生档案、导入、月度等级 | 维护本人负责学生 | 查阅全部、导出、打印；禁止写入 |
| 谈话记录、周台账 | 填写本人记录 | 查阅全部、导出、打印；禁止写入 |
| 班级、心理委员、沿用名单 | 管理本人班级 | 查阅全部、导出；禁止设置与交接 |
| 心理委员原表表头 | 维护本人的学院联系人 | 只读，按各自表头导出 |
| 降级出库申请表 | 填写、保存与查看历史 | 查阅全部、历史、导出与打印；禁止写入 |
| 假期、逐日离校记录、截图 | 管理本人记录 | 查阅全部、历史与截图、按日期导出；禁止写入 |

管理员默认进入蓝色管理总览，辅导员保留绿色工作空间。业务页不向管理员提供新增、导入、编辑、保存、复制、上传或批量登记入口。查阅弹窗保留保存时间、历史版本和导出打印。

后台在服务层校验写入身份，直接调用接口仍返回 403；传入 counselorId 或伪造 role 也不能绕过。账号管理不授予业务写入权限。账号停用保留原有档案。导出与打印继续记录审计，但不修改业务内容、保存时间或历史版本。

新增迁移 014（SQLite / MySQL）隔离心理委员表头；既有学院表头保留为只读默认值。同学院表头不一致时，管理员导出分别生成学校原表后打包，避免混用联系人。

验证：`node --test server/test/admin-readonly.test.js` 覆盖管理员业务写入拒绝、数据及时间不变、跨辅导员查阅、原表导出和账号开通。`npm run test:admin:web` 检查六个业务页面入口、只读明细及截图、历史、导出打印、窄屏导航和退出后的角色配色隔离。
