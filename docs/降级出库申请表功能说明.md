# 降级、出库申请表

本次范围为在线填写、保存记录、查看历史及按学校原表打印，不包含统计图表或审批流程。保存表格不会自动修改学生档案的月度等级，也不会删除学生档案。

## 使用

进入左侧“降级、出库申请表”，点击“填写申请表”。辅导员从本人学生档案中选择学生；管理员仅能查看、查询历史、导出和打印，界面没有新建与保存入口，接口也拒绝管理员写入。姓名、学院、年级、专业和现等级会从档案带入，填写人仍须核对，进库日期必须据实填写。

每份表对应一个学院，可以添加 1—30 名学生。可先保存草稿；填写必填项目后选择“保存完整表格”。“已填写”只表示表格字段填全，不代表已经获得评估或审批。签章日期、心理中心意见可留空，签字盖章区保留供纸质办理。

已保存内容可再次编辑，每次保存记录北京时间、操作人和版本。辅导员只能访问本人负责的申请，管理员可查看全部。可按学期、辅导员、状态、首次保存日期或关键词查询；历史版本保留每次保存时的完整内容。

## 打印及导出

根据版式校对意见，补齐合并标题区域的四边，使标题和下方表格组成完整外框，消除右上角孤立的竖线。此修正应用于每个分页的 Excel、PDF 和在线预览；原始模板文件不改写。

以用户提供的《心理动态库学生降级、出库申请表 (4)(1).xlsx》为模板。保留 11 列、原列宽、原行高、字体定义、原有红色字体、边框、合并单元格、A4 纵向和页边距。填写区增加换行，固定行高不自动伸长，不缩小字号。签章日期和心理中心意见写入原有对应区域。

原表较宽，设置适应一页宽，避免列被拆到另一张纸。每 3 名学生重复整份原表并手动分页，各页均包含标题、表头、签字盖章及心理中心意见区。Excel 保留原模板的空白 Sheet2、Sheet3。预览和打印的 PDF 由同一份 Excel 转换生成，打印时选择 A4、实际大小（100%）。

PDF 依赖 LibreOffice 和中文字体，浏览器内预览还需要 Poppler 的 `pdftoppm`。页面将实际 PDF 转为 300 DPI 图片，预览和浏览器打印使用这些页面，下载 PDF 保留矢量文字。本机用兼容宋体展示，Excel 仍保留原表“宋体”定义。若要求字体字形完全一致，需在打印环境安装并配置学校原表字体。较长内容可完整保存，超出固定空间时导出会提示精简，不会静默截断。正式部署需在学校实际字体和打印机上再次核对。

## 本地预览及校验

`npm run preview:applications` 仅监听 `127.0.0.1:8790`，打开 `http://127.0.0.1:8790/web/#applications`。预览使用虚构学生和内存数据库，重启会重置演示记录；正式服务使用配置的持久化数据库，申请正文和历史版本沿用现有加密机制。

`npm run test:applications:web` 检查辅导员填写、管理员只读查阅及导出、草稿、完整保存、历史、PDF/Excel 下载、未保存修改提示、手机宽度和退出清理。后端 `server/test/grade-applications.test.js` 检查越权、加密、幂等、版本冲突、字段校验、原表格式、4 人两页 PDF 及关闭重开持久保存。SQLite 和 MySQL 均增加迁移 012；本机实际运行验证 SQLite，MySQL 需在目标数据库环境执行迁移和验证。
