# 后端测评数据闭环说明

## 1. 本阶段范围

本阶段只建设“学生提交测评结果—服务器持久化—风险事件生成—辅导员授权查看”链路，不开发学生首页、复杂题型、雷达图、心理科普、学生投稿、FAQ 或人格探索功能。

## 2. 数据流

1. 用户仍可使用原有演示账号登录小程序。
2. 启用后端同步后，小程序在后台换取八小时后端令牌。
3. 学生提交测评时先保存在本地，并写入离线同步队列。
4. 网络可用时，小程序使用唯一 `submissionId` 提交问卷版本、评分版本、答案索引和结果。
5. 服务器不信任客户端身份或分数，按固定规则重新计算并核对。
6. 结果落入 SQLite；达到阈值或触发关键题时，同一事务创建风险事件。
7. 辅导员按“账号—学期—班级”分配关系读取班级统计、学生必要摘要和风险事件。
8. 网络失败时结果保留在队列中；永久版本错误进入失败队列，避免无限重试。

## 3. 已实现数据表

- `users`：三类账号和 PBKDF2 密码摘要。
- `classes`：班级基础信息。
- `semesters`：学期和唯一当前学期。
- `counselor_class_assignments`：按学期保存辅导员数据范围。
- `assessment_tasks`：固定学期、问卷版本和评分版本。
- `assessment_results`：结果、版本快照和答案快照。
- `risk_events`：关注、较高和紧急风险事件及跟进状态。
- `audit_logs`：登录、提交、查看和管理操作审计。
- `auth_login_attempts`：后端登录失败次数和临时锁定。

## 4. 权限规则

| 操作 | 学生 | 辅导员 | 管理员 |
|---|---:|---:|---:|
| 提交本人测评结果 | 允许 | 禁止 | 禁止 |
| 查询本人结果 | 允许 | 禁止 | 禁止 |
| 查询授权班级摘要 | 禁止 | 允许 | 默认禁止 |
| 查看原始答案 | 默认禁止 | 默认禁止 | 默认禁止 |
| 跟进授权风险事件 | 禁止 | 允许 | 默认禁止 |
| 创建/切换学期 | 禁止 | 禁止 | 允许 |
| 分配辅导员班级 | 禁止 | 禁止 | 允许 |

管理员默认也不能查看心理原始答案，防止把系统运维权限等同于心理业务权限。

## 5. 验收状态

- 后端接口测试覆盖匿名拦截、三角色登录、版本锁、服务器复算、防分数篡改、幂等提交、风险事件、班级越权、必要摘要、跟进状态、历史学期保留和新学期重新授权。
- 小程序同步测试覆盖默认关闭、后端登录、离线排队、成功回写、永久失败隔离和网络失败重试。
- 正式部署、学校 API、SSO、加密密钥托管和生产数据库不属于本阶段完成范围。
