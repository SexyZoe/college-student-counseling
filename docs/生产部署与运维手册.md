# 数智心港湾生产部署与运维手册

> 更新日期：2026-08-14
> 当前适用版本：后端 `0.2.x` 容器基线
> 安全要求：学校书面批准前只允许虚构或脱敏测试数据。

## 一、当前交付边界

当前后端已经具备容器化、健康/就绪检查、服务端权限、版本化迁移、MySQL连接池、敏感字段加密、会话撤销、限流、结构化日志、Prometheus指标、加密备份和自动化测试。

当前交付边界如下：

- SQLite容器可用于开发、演示和快速接口联调；
- MySQL 8.4运行模式已通过测评、风险、任务、内容、人员导入回滚和审计契约测试；
- 正式环境必须使用学校MySQL或华为云RDS，并配置TLS CA、最小权限账号、平台备份和告警；
- 在目标环境完成备份恢复、综合压力和安全验收前，不得把当前版本标记为正式生产版；
- 学校统一认证、学生数据API、正式域名和证书必须由学校提供或批准。

## 二、环境分层

| 环境 | 数据 | 用途 | 最低要求 |
|---|---|---|---|
| 开发 | 虚构数据 | 日常开发、微信开发者工具联调 | 单机Docker、SQLite卷 |
| 测试 | 虚构或脱敏数据 | 自动化、接口、压力与恢复演练 | 独立密钥、独立数据库 |
| 预发布 | 脱敏数据 | 学校网络、统一认证、真机验收 | 与生产相同拓扑，不共用数据 |
| 生产 | 经批准的真实数据 | 正式服务 | MySQL/RDS、高可用、HTTPS、WAF、监控、备份 |

任何两个环境都不得共用数据库、`AUTH_SECRET`、数据加密密钥或备份加密密钥。

## 三、密钥和配置

本地生成三个不同的随机密钥：

```bash
openssl rand -hex 32
openssl rand -hex 32
openssl rand -hex 32
```

分别用于：

- `AUTH_SECRET`：签发登录令牌；
- `DATA_ENCRYPTION_KEY`：加密答题快照和风险跟进记录；
- `BACKUP_ENCRYPTION_KEY`：加密数据库备份。

密钥必须存放在学校密钥管理平台、华为云KMS/云密钥管理或受控的部署密钥中，禁止写入Git、镜像、聊天截图和日志。`DATA_ENCRYPTION_KEY_ID`和`BACKUP_ENCRYPTION_KEY_ID`用于标记密钥版本；轮换旧密钥前必须完成历史数据重加密或保留受控解密能力。

生产环境至少设置：

```text
NODE_ENV=production
AUTH_SECRET=<至少32字符>
DATA_ENCRYPTION_KEY=<32字节密钥>
DATA_ENCRYPTION_KEY_ID=primary-2026-01
SEED_DEMO_DATA=false
CORS_ALLOWED_ORIGINS=https://已批准的管理后台域名
TRUST_PROXY=true
METRICS_TOKEN=<独立监控令牌>
LOG_LEVEL=info
DATABASE_ENGINE=mysql
MYSQL_HOST=<数据库地址>
MYSQL_PORT=3306
MYSQL_DATABASE=<数据库名>
MYSQL_USER=<最小权限应用账号>
MYSQL_PASSWORD=<部署平台注入>
MYSQL_SSL_CA=/run/secrets/mysql-ca.pem
MYSQL_CONNECTION_LIMIT=20
```

生产环境会拒绝缺失密钥、短密钥或`SEED_DEMO_DATA=true`的配置。

## 四、开发容器启动

```bash
cp .env.compose.example .env
```

编辑`.env`中的密钥，然后：

```bash
docker compose up --build -d backend
docker compose ps
curl http://127.0.0.1:8787/health
curl http://127.0.0.1:8787/ready
docker compose exec backend node scripts/smoke-test.js
```

停止但保留数据：

```bash
docker compose down
```

`docker compose down -v`会删除本地数据卷，只能在确定不需要测试数据时使用。

## 五、MySQL迁移与业务运行时

只验证MySQL结构与迁移：

```bash
docker compose --profile mysql up --build mysql mysql-migrate
docker compose ps
```

使用 MySQL 启动业务后端并执行运行时验收：

```bash
docker compose --profile mysql-runtime up --build -d backend-mysql
docker compose exec backend-mysql node scripts/smoke-test.js
docker compose exec backend-mysql node scripts/runtime-contract-test.js
```

迁移具备：

- 按编号顺序执行；
- SHA-256校验，禁止改写已执行迁移；
- MySQL命名锁，避免多个发布实例同时迁移；
- 重复执行幂等；
- 自动检查业务表和唯一当前学期约束。

新增数据库变更必须创建新的`server/src/migrations/mysql/NNN_name.sql`和对应SQLite迁移，禁止修改历史文件。

MySQL运行时通过`AsyncLocalStorage`保证事务内查询使用同一连接。`MYSQL_CONNECTION_LIMIT`、`MYSQL_IDLE_TIMEOUT_MS`和`MYSQL_QUEUE_LIMIT`必须结合目标数据库连接上限与压测结果设置。生产环境缺失`MYSQL_SSL_CA`时服务会拒绝启动。

## 六、监控与日志

健康检查：

- `/health`：HTTP进程存活；
- `/ready`：数据库可访问，可作为负载均衡就绪探针；
- `/metrics`：Prometheus文本指标，配置`METRICS_TOKEN`后必须使用`Authorization: Bearer <token>`。

日志为单行JSON，包含请求编号、方法、标准化路由、状态码和耗时；密码、令牌、答题和跟进字段会自动遮盖。网关需要把`X-Request-Id`返回给报障人员，但不得在用户界面显示内部错误栈。

推荐告警：

| 指标 | 建议阈值 |
|---|---|
| `/ready`失败 | 连续2次立即告警 |
| HTTP 5xx比例 | 5分钟超过1% |
| P95接口耗时 | 5分钟超过1秒 |
| 登录429比例 | 5分钟异常上升 |
| 数据库连接使用率 | 超过80% |
| 备份任务 | 24小时无成功记录 |
| 磁盘使用率 | 超过75%预警、85%告警 |

## 七、SQLite加密备份与恢复演练

当前开发数据库可执行一致性快照和AES-256-GCM加密备份：

```bash
DATABASE_PATH=/绝对路径/app.db \
BACKUP_DIRECTORY=/绝对路径/backups \
BACKUP_ENCRYPTION_KEY=<32字节密钥> \
BACKUP_ENCRYPTION_KEY_ID=backup-2026-01 \
node server/scripts/sqlite-backup.js
```

只验证备份，不覆盖现有数据库：

```bash
BACKUP_FILE=/绝对路径/backups/文件.db.enc \
BACKUP_ENCRYPTION_KEY=<32字节密钥> \
BACKUP_ENCRYPTION_KEY_ID=backup-2026-01 \
node server/scripts/sqlite-restore-verify.js
```

恢复到一个不存在的新路径：

```bash
RESTORE_TARGET_PATH=/绝对路径/restored/app.db \
BACKUP_FILE=/绝对路径/backups/文件.db.enc \
BACKUP_ENCRYPTION_KEY=<32字节密钥> \
BACKUP_ENCRYPTION_KEY_ID=backup-2026-01 \
node server/scripts/sqlite-restore-verify.js
```

脚本拒绝覆盖已有目标。生产MySQL/RDS应使用平台自动备份、时间点恢复和跨区域副本，并每学期至少完成一次隔离环境恢复演练。

## 八、发布和回滚

发布前：

1. PR经过至少一名成员审核；
2. 全部自动化测试、容器构建、MySQL迁移和备份恢复CI通过；
3. 生成不可变镜像版本和SBOM，漏洞扫描无未接受的严重/高危项；
4. 在预发布环境执行迁移、冒烟、真机和权限验收；
5. 确认备份成功并记录恢复点；
6. 由业务负责人批准发布窗口和回滚决定人。

发布采用“先迁移、再滚动替换实例、最后观察指标”的顺序。应用回滚不得自动回滚数据库结构；数据库变更必须向前兼容至少一个应用版本。若出现5xx激增、就绪失败、数据写入错误或权限异常，立即停止流量、回滚应用镜像并保留日志与请求编号。

## 九、仍需外部提供

正式上线前必须由学校或云平台提供：服务器/容器规格、MySQL/RDS连接、内外网拓扑、HTTPS域名证书、WAF/网关、统一认证协议、学生组织数据接口、监控告警接收人、备份保留策略、安全测评要求和应急联系人。心理专业部门必须书面确认量表授权、评分阈值、关键题、风险响应流程和文案。
