# 学生名单导入与账号管理

管理员在「学期与组织数据 → 导入」选择 UTF-8 CSV，固定两列、固定顺序：

```csv
班级,学号
软件工程1班,20260001
软件工程1班,20260002
```

可复制页面模板或使用 [学生名单模板.csv](学生名单模板.csv)。Excel 应将学号设为文本，以保留前导零。小程序端支持 UTF-8 CSV；Web 管理端还支持 `.xlsx` 和使用逗号或 Tab 分隔的 `.txt`。最多500名学生、512KB。

## 导入规则

- 表头只接受「班级,学号」，不接受姓名、手机号、调整顺序或多余列。
- 学号按文本读取，长度4～32位，支持字母、数字、下划线、短横线；英文字母统一小写。初始密码取学号最后4位，保留前导零。
- 班级按完整名称匹配；不存在时自动创建，同名班级有多个或班级已停用时要求管理员核实。
- 新账号姓名为空，学生登录后自行填写并确认用途。
- 重复学号、格式错误或与其他角色账号冲突时，整批不能确认。
- 重复导入已有学生只更新班级，保留学生已修改的密码和已填写的姓名。
- 导入预检只生成计划；管理员确认后再单事务写入。统计的新增项包含自动创建的班级。

## 学生首次使用与改密

学生使用学号和学号后4位初始密码登录。登录成功后会弹窗提示立即改密，并进入「账号与个人资料」；学生需自行填写姓名、同意信息用途并修改临时密码，新密码长度8～64位。保存密码后重新登录即可使用测评等功能。后端同样限制未完成设置的会话，跳过前端页面也不能提交测评。

日后通过「我的 → 账号资料与修改密码」修改姓名和密码。姓名修改需确认用途；班级和学号由管理员维护。修改密码需验证原密码，成功后撤销旧会话。

不提供短信验证码、邮箱绑定或自助找回密码，不接入短信/邮件收费服务。学生可在登录页点击“忘记密码”查看流程：先联系辅导员，由辅导员联系管理员核验并重置。

## 管理员人工重置

管理员在「学生」列表选择「重置密码」，确认后将学生密码重置为**学号后4位**。学生所有旧会话失效，下次登录须重新修改密码。辅导员负责传递学生申请，但没有重置权限；其他学生同样无权重置。

## 辅导员账号与班级分配

辅导员不自行注册。管理员在 Web 管理端填写工号和姓名创建账号，系统统一设置临时密码 `123456`。辅导员首次登录后必须修改密码，在改密前后端不允许访问班级、风险跟进或内容发布等业务。

管理员按学期将班级分配给辅导员。同一学期同一班级只有一名当前负责辅导员；重新分配会结束原分配并保留历史记录。管理员也可撤销分配、停用账号或将密码重置为 `123456`。

重置操作记录管理员和目标账号，不在响应或审计日志中展示密码。

## 辅导员分配

导入后在「分配」选择班级、输入已有辅导员工号，将班级授权给该辅导员的当前学期。导入名单不会自动把班级授权给所有辅导员。

## 数据存储和回滚

学生名单不采集手机号；密码只保存 PBKDF2 摘要，导入计划和接口响应均不返回初始密码明文。

回滚新建账号/班级时执行停用，不删除历史数据。回滚更新时恢复之前的快照；若学生已经改名或改密，系统拒绝自动覆盖。新增 `005_student_accounts.sql` 同时支持 SQLite 与 MySQL，不改写旧迁移。

已有后台八列组织导入协议保留作兼容接口；小程序和 Web 的学生名单入口固定发送 `format: student-roster`，只接受两列表头。

## 新增接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/account` | 当前云端账号和待完善状态 |
| PATCH | `/api/v1/account/profile` | 学生自行填写姓名并确认用途 |
| POST | `/api/v1/account/password` | 验证原密码后改密，撤销旧会话 |
| POST | `/api/v1/admin/students/:studentId/reset-password` | 管理员人工重置 |

开发验证：`npm test`。真实 MySQL 账号测试仅允许使用隔离库 `shuzhi_accounts_test`，不能对在线数据库运行。
