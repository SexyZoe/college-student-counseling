# 一级学生周台账

辅导员进入“一级学生周台账”，选择学期与教学周后查询。名单根据学生档案中的等级及生效日期生成：所选周内曾为一级的学生进入名单；没有新月评级时沿用最近一次等级。降为其他等级后，后续周不再自动列入，已经保存的台账继续保留。

## 填写与历史

- 学院、姓名、联系方式、宿舍、辅导员及学生帮扶资料自动带入。校区、专业可以在档案或首次周记录中补齐。
- 每周分别填写心理状况和备注。可以先保存草稿；保存完成记录需要校区、专业和心理状况。
- 新记录默认将校区、专业同步到学生档案；编辑已保存记录时由辅导员主动勾选同步。历史快照中的其他基本信息保持不变。
- 支持补录和修改，每次保存保留一个版本，显示首次保存及最后保存时间。同一学生同一周保持一份记录，旧页面保存冲突时提示重新打开。
- “往周记录”查看该学生此前已保存内容；“修改历史”查看本周每次保存内容。

学生档案增加“校区”“专业（周台账使用）”“等级生效日期”。旧的月度评级默认从当月1日生效；新录入和调整等级时，应核对实际生效日期。

## 管理员查询

管理员可查看全部辅导员的记录，按辅导员、学院、校区、姓名或学号、学期、周次和填写状态查询。管理员只读，不代替辅导员填写。管理员可设置第1教学周的周一，默认采用学期开始日期所在周的周一；学期已有记录后不能再调整。

## 学期管理与后续学期

管理员侧栏提供“学期管理”。每个学期由管理员按学校校历填写名称、起止日期和第1教学周的周一。可以提前创建下一学期，创建后所有辅导员都能在周台账中选择，无需修改代码或重新导入学生档案。新建学期默认“未开始”，管理员到开学时再选择“设为当前学期”；旧学期归档但仍可查询。

未填写教学周设置的旧学期明确显示“默认推算”，并在打印和Excel的日期标题中注明。学期已有周台账后，不能改动名称、起止日期和教学周起点；允许在不改变周次的前提下确认原有默认起点。没有记录的学期可以编辑日期及教学周。

本地演示包含“2026-2027学年第二学期”示例选项，示例起止日期不代表学校正式校历，界面会显示演示提示。实际使用时请管理员按学校公布日期配置。

## 导出与打印

Excel 使用学校提供的《严重心理问题学生周台账表》原模板，保持标题、合并单元格、12列顺序与列宽。日期范围和教学周自动生成。正文自动换行、按内容计算行高；单条内容超过 Excel 行高容量时明确提示精简，保存内容完整保留。

打印使用相同12列和查询范围，A4横向，可在浏览器打印窗口保存PDF。浏览器打印重新排版，不承诺与 Excel 打印逐像素一致。

默认要求当前查询全部记录已填写，才可导出或打印。也可以筛选“已填写”，或明确勾选“包含未完成记录”，未完成状态会注明在心理状况栏。导出和打印记录审计。
