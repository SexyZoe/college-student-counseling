# 数智心港湾

面向大学生心理健康教育、状态自评和学校支持工作的微信小程序原型，包含学生端、辅导员端和管理员端。

> 本项目提供心理健康教育和风险筛查辅助，不构成医疗诊断，不能替代心理咨询师、精神科医生或学校危机干预流程。

## 校园云实例部署（2026-09-17）

已在学校 Ubuntu 实例部署 Nginx + Node.js + MySQL，入口为校园内网 `http://172.18.132.12`，就绪检查为 `/ready`。数据库与后端运行在同一实例的独立容器中，使用持久化数据卷；不要求另行申请学校数据库。

小程序默认连接此实例，云端认证成功后才建立页面会话。首次调试请按[校园云部署说明](deploy/README.md)设置微信开发者工具；旧的本地配置可能覆盖默认地址。

已完成 Docker 网段冲突修复、网关部署、每日加密备份、隔离恢复演练和健康检查定时器。详见[部署验收记录与简历描述](docs/校园云部署验收记录.md)。当前是校园内网学习环境，尚未完成公网 HTTPS、微信正式发布与真实业务接入。

## 当前功能

### 身份认证

- 学生、辅导员和管理员统一登录入口与角色分流
- 默认使用云端账号认证；显式离线模式保留八小时本地演示会话
- 受保护页面的角色守卫与越权访问拦截
- 学生名单固定为「班级、学号」；学号登录，初始密码为学号后4位，首次自行填写姓名并强制改密
- 辅导员账号由管理员统一创建，临时密码为 `123456`；管理员按学期分配负责班级，辅导员首次登录强制改密
- 学生自主改密、管理员人工重置、旧会话撤销；不接入短信或邮件找回

### 学生端

- 学号和独立密码演示登录、可选微信身份绑定
- 当前学期、班级、辅导员和测评任务
- 8 套心理量表，共 114 道题
- 答题暂存、漏答检查、反向计分、风险标准化、关键题触发、结果解释和五维雷达图
- 每次提交固定问卷版本、评分规则和学期归属，历史结果不随新规则重新计算
- 历史测评趋势、心理科普、FAQ、隐私授权和求助资源
- 与心理风险筛查分离的 16 型人格探索
- “成长与价值”课程思政内容

### 辅导员端

- 授权班级、学生人数、完成率和风险摘要
- 班级学生筛选、风险分布及五维平均值
- 学生测评必要摘要、风险确认和跟进记录
- 课程思政内容投稿

### 管理员端

- 学期创建、当前学期切换、历史学期保留，以及学生、班级和辅导员分配关系原型
- CSV 人员导入、字段校验、差异预览、事务确认和整批回滚
- 测评任务创建与发布
- 心理科普和课程思政内容审核
- 敏感操作审计概览

### 后端测评数据闭环

- Node.js 后端同时支持 SQLite 开发模式与 MySQL 8.4 运行模式，可持久化账号、学期、任务、结果、风险事件和审计日志
- 学生结果幂等提交、离线队列和网络恢复重试
- 服务器按固定规则重新评分，拒绝伪造身份、篡改分数或版本不一致的提交
- 辅导员按学期和班级授权实时查询必要摘要，不返回学生原始答案

### 管理员人员数据导入

- 两列 CSV 批量创建学生账号和班级，姓名由学生登录后填写；另有辅导员班级分配入口
- 导入前检查重复账号、角色冲突、缺失引用和弱初始密码
- 展示新增、更新、无变化及错误明细，管理员确认后才写入
- 单事务导入、逐项变更快照、幂等确认和安全整批回滚

## 本地运行

1. 安装微信开发者工具。
2. 克隆本仓库。
3. 在微信开发者工具中导入仓库根目录。
4. 如需重新构建依赖，执行 `npm install` 后在开发者工具中选择“工具 → 构建 npm”。
5. 按[校园云部署说明](deploy/README.md)连接校园服务，使用演示账号逐角色验证；纯本地演示可在调试控制台执行 `wx.setStorageSync("backendSyncEnabled", false)` 后重新编译。

如需验证多人数据闭环，另开终端执行 `AUTH_SECRET="本地随机密钥" npm run server`，再按照 [后端启动说明](server/README.md) 启用小程序后端同步。

### 使用 Docker 运行后端

1. 复制Compose环境变量模板：

   ```bash
   cp .env.compose.example .env
   ```

2. 将`.env`中的`AUTH_SECRET`替换为至少32个字符的本地随机值。
   建议同时用`openssl rand -hex 32`生成`DATA_ENCRYPTION_KEY`，不要与登录密钥相同。
3. 构建并启动：

   ```bash
   docker compose up --build -d
   ```

4. 验证服务和核心接口：

   ```bash
   curl http://127.0.0.1:8787/health
   curl http://127.0.0.1:8787/ready
   docker compose exec backend node scripts/smoke-test.js
   ```

5. 停止服务：

   ```bash
   docker compose down
   ```

普通`docker compose down`不会删除SQLite测试数据卷。只有明确需要清空虚构测试数据时才使用`docker compose down -v`。

如需验证与正式部署拓扑接近的 MySQL 运行模式：

```bash
docker compose --profile mysql-runtime up --build -d backend-mysql
docker compose exec backend-mysql node scripts/smoke-test.js
docker compose exec backend-mysql node scripts/runtime-contract-test.js
```

## 隐私与伦理

- 只收集完成身份确认、测评和支持服务所必需的信息。
- 心理测评回答、结果和风险记录应按敏感个人信息保护。
- 辅导员只能访问被授权班级的必要摘要。
- 趣味人格探索和课程思政内容不进入心理风险判断。
- 不将学生心理数据用于处分、公开排名、广告或无关评价。
