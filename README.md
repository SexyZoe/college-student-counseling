# 数智心港湾 · 校园内网网页应用

学生、辅导员、管理员使用同一个校园网址。连接学校 Wi-Fi 后，扫码或用手机/电脑浏览器打开即可；不依赖微信小程序、微信登录、外部 CDN 或第三方字体。

**当前代码已迁移到 Web，正式接入真实学生仍需学校完成专业审核、隐私与支持渠道确认、HTTPS 和部署验收。** 原量表及阈值保持历史版本，用于迁移一致性验证；尚不能把原型规则当作经过专业审定的临床标准。

## 功能

- 学生：学号登录、首次补充姓名和强制改密、8套测评共114题、任务/自主测评、单独同意、当前标签页草稿、刷新恢复、断网重试、服务端评分与幂等保存、结果与历史趋势。
- 学生内容：已审核心理科普与成长文章、搜索、18条常见问题、28题人格探索、隐私说明和学校求助信息。人格结果不上传至风险系统。
- 辅导员：授权班级、学生必要摘要、风险跟进、图文/视频投稿；不展示原始答案。
- 管理员：学期创建与切换、学生名单预检/确认/回滚、学生密码重置、辅导员创建/启停/重置和班级分配、测评任务发布/结束、内容审核/下架、审计记录。
- 运行：Node.js + SQLite（开发）/ MySQL（部署）、同源网页和API、HttpOnly 会话 Cookie、CSRF 检查、角色与班级授权、敏感答案加密、备份与就绪检查。

## 本地启动

需要 Node.js 22.13+（建议24）：

```bash
npm --prefix server ci
npm start
```

打开 `http://127.0.0.1:8787/web/`。本地默认虚构演示账号：学生 `2024001`、辅导员 `T001`、管理员 `admin`，密码均为 `123456`。正式环境禁止启用演示数据。

## 验证

```bash
npm test
npm ci
npx playwright install chromium
npm run test:web
```

浏览器测试创建独立内存数据库，不访问校园实例，不修改真实账号。截图输出到忽略的 `artifacts/`。本机使用已安装 Chrome 可运行 `BROWSER_CHANNEL=chrome npm run test:web`。

## 正式部署

详见 [校园 Web 部署](docs/校园Web上线手册.md)、[功能迁移记录](docs/Web迁移与恢复.md)、[学校确认事项](docs/学校与专业审核待办清单.md)。

正式环境入口采用学校提供的 HTTPS 域名，后端和数据库仅在服务器/容器内部开放。学校网络策略负责确保外网不能访问；二维码与前端代码不会自动实现内网隔离。

新建空数据库使用 `server/scripts/bootstrap-admin.js` 初始化唯一管理员，无需加载演示数据。`npm run check:release` 执行只读配置预检，不替代学校批准。

项目不构成医疗诊断，不替代线下咨询与危机干预流程。量表版权、专业审核及学校业务授权需由项目负责部门确认。
