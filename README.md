# 数智心港湾 · 学生心理关怀档案管理

当前项目面向学校内部的**管理员和辅导员**，围绕需要心理关注学生的登记档案开展工作。学生不再登录本系统。原学生服务相关代码与历史数据暂时保留，新入口已切换为档案管理。

## 已完成的功能

- 管理员开通、启停和重置辅导员账号；辅导员自行维护姓名、学院与联系方式。
- 辅导员登记和编辑自己负责的学生档案；管理员只读查看全部数据、按辅导员筛选及导出打印，不能代为登记、导入或修改。
- 按提供的注册表录入学院、姓名、性别、年级专业、联系方式、宿舍、辅导员/联系方式、学生帮扶/班级职务/联系方式、领导帮扶、月度等级和备注；另有可选学号辅助核对重复。
- 月度等级保存历史，不预设学校尚未确认的等级标准。
- `.xlsx` 模板下载和批量导入：先预检、定位错误行、提示重名，再确认入库；重复确认不会重复写入。
- 按查询结果或勾选学生导出 Excel，按指定月份横向打印或通过浏览器保存 PDF。打印使用原表的12列，Excel 末尾附加可选学号列。
- HttpOnly 会话、CSRF 检查、后端数据归属校验、修改冲突提示、导出/打印审计。正式环境配置的数据加密密钥同时保护档案与导入预览。
- 学生谈话记录：独立保存每次谈话、继续编辑、记录保存与修改时间；管理员只读查看全部记录。
- 一级学生周台账：按评级生效日期自动生成每周名单，填写心理状况和备注，保留历史快照与修改版本；管理员可汇总查询、导出原表 Excel 和打印。详见 [周台账功能说明](docs/一级学生周台账功能说明.md)。本地虚构数据演示：`npm run preview:weekly`。
- 班级心理委员：按学期管理班级及多名委员，辅导员维护本人名单，管理员汇总查看；按教师、学院选择文件并预览学校原表正反面，可单独下载 Excel 或仅打包所选文件。详见 [心理委员功能说明](docs/班级心理委员功能说明.md)。本地演示：`npm run preview:committee`。
- 学校原表导出：沿用提供的 Word 模板，支持 `.doc` / PDF 与打印预览，生成时比较页数、页面尺寸和表格边线，拒绝内容挤大原表。详见 [学生谈话记录功能说明](docs/学生谈话记录功能说明.md)。

## 本地运行

需要 Node.js 22.13+（建议24）。

```bash
npm --prefix server ci
npm start
```

打开 `http://127.0.0.1:8787/web/`。开发环境的虚构演示账号：管理员 `admin`，辅导员 `T001`，密码均为 `123456`。新开通的辅导员账号首次登录必须修改临时密码。

开发环境默认使用 SQLite，新增表会自动迁移。已有平台的学生账号或名单**不会自动成为心理关注档案**，需由辅导员登记或导入。正式环境使用 MySQL 时，先运行 `npm --prefix server run db:mysql:migrate`，再启动服务。

详细操作见 [学生登记功能说明](docs/学生登记功能说明.md)。

## 验证

```bash
npm test
npm run test:web
```

浏览器测试需要 Playwright Chromium；也可使用本机 Chrome：

```bash
BROWSER_CHANNEL=chrome npm run test:web
```

测试使用独立内存数据库及虚构资料，不接触真实档案。`artifacts/` 下保存界面截图及打印 PDF。历史学生服务的接口回归测试通过显式 `staffOnly:false` 测试配置运行，实际启动配置固定为两角色系统。

## 部署与历史资料

继续使用现有 Node.js + SQLite / MySQL 部署方式。正式环境的密钥、HTTPS、备份和校园内网配置见 [校园Web上线手册](docs/校园Web上线手册.md)。旧文档中的学生端、测评与班级分配流程属于前一版需求，当前第一阶段以本 README 和学生登记说明为准。

本阶段的本地验证覆盖 SQLite、Chrome 和本地 LibreOffice 文档转换。原表定义的宋体、黑体尚未安装，PDF 使用兼容中文字体并在界面提示；Word 保留字体定义。完全相同的字体效果需安装学校提供的原字体。MySQL 迁移脚本随代码提供，仍需在目标 MySQL 实例执行迁移与验收；尚未进行生产部署。

## 降级、出库申请表

本地预览使用 `npm run preview:applications`，支持辅导员在线填写、保留保存时间和历史版本；管理员只读查阅、导出和打印，并按学校 Excel 模板预览打印、导出 PDF/Excel。详见[功能说明](docs/降级出库申请表功能说明.md)。本次不包含统计图表。

## 假期学生离校统计

`npm run preview:holidays` 提供左侧日历、右侧学生名单、逐日登记与家长报备截图上传，支持按日期和所选学生导出 Excel 并嵌入截图；默认清晰排版，也可选学校原版列宽及 A3/A4 横向打印。详见[功能说明](docs/假期学生离校统计功能说明.md)。

## 管理员与辅导员权限

管理员使用蓝色管理控制台，可开通、启停、重置辅导员账号，管理学期校历，并查阅、打印、导出各辅导员保存的材料。所有业务写入接口均拒绝管理员：学生档案、Excel 导入、谈话、周台账、班级与委员、申请表、假期与截图。辅导员仅能维护本人负责的数据，管理账号不授予业务代填权限。详见[角色权限说明](docs/角色权限说明.md)。
